# Как работать с personal-guide

> Практическое руководство по эксплуатации. Пополняется по мере использования.

## Структура

```
personal-guide/
├── README.md              # Общее описание, ссылки, инструкция по обновлению
├── profile.md             # Твой RCS-профиль, ритм, неудовлетворённости
├── worldview.md           # Мировоззренческая фаза, мемы, принципы
├── methods.md             # Методы под текущий bottleneck
├── HOWTO.md               # Этот файл
├── weekly/
│   └── 2026-W20.md        # Гипотеза и план текущей недели
├── daily/
│   └── 2026-05-17.md      # Тактика конкретного дня
└── history/
    └── (архив прошлых weekly/daily)
```

## Ежедневный цикл

### Утро: Day Open (5–10 мин)

1. Открой `weekly/<текущая-неделя>.md` — напомни себе гипотезу недели.
2. Создай или открой `daily/<сегодня>.md`.
3. Запиши **1 главный приоритет** на день (не 5, не 3 — один).
4. Выбери **1 метод** из `methods.md`, который будешь применять сознательно.
5. Заблокируй время в календаре под self-dev слот (если ещё не заблокирован).

### День: работа

- Помодоро: 25 мин фокуса → 5 мин перерыва.
- Если задача ≤2 мин — делай сразу.
- Перед любым блоком глубокой работы: 30 сек на вопрос «Что я делаю и зачем?»

### Вечер: Day Close (5–10 мин)

В `daily/<сегодня>.md` запиши:
- 3 достижения (даже если день был провальным — найди 3)
- 1 улучшение на завтра
- Самочувствие по 5-балльной шкале

Если есть незакрытые задачи — перенеси в `daily/<завтра>.md` или верни в `weekly/...`.

## Еженедельный цикл

### Понедельник: стратегический день

- Пересмотри `worldview.md` — актуальны ли мемы?
- Проверь `profile.md` — изменился ли bottleneck?
- Обнови `weekly/<новая-неделя>.md`:
  - Сформулируй **новую гипотезу** (одно предложение, проверяемое)
  - Запланируй фокусы по дням
  - Проверь, что self-dev слот защищён

### Воскресенье: Week Close (15–30 мин)

1. Открой `weekly/<прошедшая-неделя>.md`.
2. Заполни секцию **Ретро**:
   - Что сработало?
   - Что не сработало?
   - Один инсайт.
   - Следующая гипотеза (заготовка для понедельника).
3. Перемести файл в `history/`:
   ```bash
   git mv weekly/2026-W20.md history/2026-W20.md
   ```
4. Создай новый `weekly/2026-W21.md` по шаблону.

## Когда что менять

| Что | Как часто | Триггер |
|-----|-----------|---------|
| `daily/` | Каждый день | Утро / вечер |
| `weekly/` | Каждую неделю | Пн — новая, Вс — ретро + архив |
| `methods.md` | Каждые 2–4 недели | Смена bottleneck или домена |
| `profile.md` | Каждый месяц | Новые неудовлетворённости, рост baseline |
| `worldview.md` | Каждые 1–2 месяца | Переход фазы, смена мемов |
| `README.md` | По необходимости | Изменение инструментария |

## Работа в Kimi Code CLI

Ты работаешь в Kimi — это нормально, но часть функций недоступна без Claude Code + MCP.

### Что работает в Kimi

- Создавать/редактировать `daily/` и `weekly/` файлы.
- Обновлять `methods.md`, `profile.md`, `worldview.md`.
- Генерировать планы на день/неделю по твоему запросу.
- Git: commit, push, история.

### Что требует Claude Code

- **Полная пересборка** через `/personal-guide-render` — читает Память.Derived, выбирает заготовки stage×domain.
- **Обновление RCS** — `dt_read_digital_twin` доступен только через MCP `aisystant`.
- **Шаблоны ступеней** — лежат в `PACK-personal`, который не склонирован локально.

**Обходной путь:** если нужна полная пересборка — запускай `/personal-guide-render` в Claude Code. Между пересборками спокойно работай в Kimi.

## Примеры запросов к Kimi

> Не запоминай синтаксис — просто говори обычными словами.

- «Собери план на завтра» → Kimi создаст `daily/2026-05-18.md` по шаблону.
- «Переделай methods под bottleneck M2» → обновит `methods.md`, оставив только мета-навыки.
- «Итоги недели» → архивирует `weekly/2026-W20.md` в `history/` + создаст `weekly/2026-W21.md`.
- «Добавь в worldview мем 'система > цель'» → вставит строку в `worldview.md`.

## Git-ритуал

После каждого значимого изменения:

```bash
cd ~/IWE/personal-guide
git add -A
git commit -m "daily: 2026-05-18 — фокус на time-blocking"
git push origin main
```

Не копи изменения — коммить в конце дня. История коммитов = история твоего развития.

## Если что-то пошло не так

| Проблема | Решение |
|----------|---------|
| Забыл делать daily 3 дня | Не догоняй. Начни с сегодняшнего дня, не переписывая прошлое. |
| Гипотеза недели провалилась | ОК. Запиши почему — это данные. Новая гипотеза в следующий понедельник. |
| Bottleneck поменялся посреди недели | Обнови `methods.md`, но гипотезу недели не трогай — проверь до конца. |
| Не хватает шаблона из PACK-personal | Временно пиши своими словами. Полная пересборка — в Claude Code. |
| Хочу бросить | Открой `profile.md` → перечитай неудовлетворённости. Они никуда не делись. |
